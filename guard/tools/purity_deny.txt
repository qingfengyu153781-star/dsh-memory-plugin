# _guard · 通用层纯净性禁止清单（R-56 / g_purity）—— **中性默认件**
#
# 每行一个禁止项（**正则**，大小写敏感）；`#` 注释与空行跳过。
#
# 语义：`guard/gates/*.py` 与 `guard/*.py` 是**跨项目通用层** ——
#   不许在**代码**里出现具体项目的内容（路径 / 专有名字），否则换个项目就不能用。
# ★判据只扫【代码】：字符串字面量与 import —— **不扫注释与 docstring**，
#   所以"本件移植自某处"这类**注明出处**是允许的（那不是依赖）。
# ★正确做法：路径从配置读（tools/*.json、projects/*.yaml），代码里用相对定位。
#
# ── ★★ 2026-10-16 为什么本件只放"通用形态"──────────────────────────────
# 原来这份清单里列的是**我们自己的项目名**（好几个）与本机路径。
# 那是**私有内容**：把它随公开仓发出去，就等于**用"治泄露的清单"再泄露一次**。
# ⇒ 拆两份：
#     · 本件（随仓发布）：只放**与具体机器/项目无关的通用形态**；
#     · `purity_deny.local.txt`（**已 gitignore**）：你的项目名/本机路径写这里，
#       `g_purity.load_deny()` 会把两份**并起来**用。
#
# —— 通用形态①：把机器绝对路径写死进通用层 ——
[A-Za-z]:[\\/]+(?:Users|agent|deepseekzmd)[\\/]+
# —— 通用形态②：MSYS/WSL 的盘符挂载写法写死进通用层 ——
/cygdrive/[a-z]/
